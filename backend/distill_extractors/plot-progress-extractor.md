# 情节进度提取器

## 任务
你是一个小说情节分析专家。请仔细阅读下面给出的小说章节内容，提取出各条情节线的当前推进进度。这些进度信息将作为后续章节生成的记忆上下文，帮助AI把握故事已发展到哪一步，避免重复或跳跃。

## 提取要求
识别章节中涉及的所有情节线（主线及支线），对每条情节线提取以下字段：

- **name**：情节线名称，如"主线·复仇之路""支线·师妹身世""支线·宝物争夺"等
- **type**：情节线类型，"主线" 或 "支线"
- **current_step**：当前推进到哪一步（一句话概括最新进展）
- **progress**：进度百分比估算（0-100的整数，表示该条线的完成度）
- **key_events**：已发生的关键事件数组，按时间顺序排列，每项含：
  - `event`：事件描述（一句话）
  - `chapter`：发生在第几章（数字）
- **next_hook**：下一步的悬念/钩子（章节结尾留下的未解之谜或即将到来的冲突）

## 输出格式
返回JSON数组，放在 ```json 代码块中。示例如下：

```json
[
  {
    "name": "主线·复仇之路",
    "type": "主线",
    "current_step": "林川查知父亲死因与赵长风有关，但尚缺关键证据",
    "progress": 35,
    "key_events": [
      {"event": "林川被赵长风暗算重伤", "chapter": 1},
      {"event": "林川在后山密室疗伤时发现父亲遗书残页", "chapter": 2},
      {"event": "残页暗示父亲之死与藏经阁某份卷宗有关", "chapter": 3}
    ],
    "next_hook": "藏经阁里那份卷宗究竟记载了什么？林川能否避开守卫潜入？"
  },
  {
    "name": "支线·苏婉身世",
    "type": "支线",
    "current_step": "苏婉对自身来历产生怀疑，开始暗中调查",
    "progress": 15,
    "key_events": [
      {"event": "苏婉发现自己与宗门禁地壁画上的女子容貌相似", "chapter": 2}
    ],
    "next_hook": "苏婉的真实身份是什么？她与禁地有何渊源？"
  }
]
```

## 注意事项
1. 情节线名称要清晰区分主线和支线，主线通常只有1条，支线可有0到多条
2. 关键事件必须按章节中的实际时间顺序排列
3. 进度百分比是估算值，基于该情节线的故事弧度进展程度
4. next_hook 是章节结尾留下的悬念，如果没有明确悬念，描述即将到来的下一个冲突点
5. 不要臆造原文没有的事件，所有事件必须能在章节中找到依据
6. 如果某条情节线在给定章节中完全没有推进，不要列入结果
