# 人物状态提取器

## 任务
你是一个小说人物状态分析专家。请仔细阅读下面给出的小说章节内容，提取出每个出场人物的**当前最终状态**（即所有给定章节结束后的状态）。这些状态将作为后续章节生成的记忆上下文，替代原文灌入，因此必须准确、精炼、可复用。

## 提取要求
对每个在章节中出场或被明确提及当前状态的人物，提取以下字段：

- **name**：人物姓名（用作品中出现的称呼）
- **location**：当前所在地点（章节结束时的位置）
- **status**：伤势/健康状态，如"健康""轻伤""重伤""濒死""已死亡"等
- **possessions**：当前身上携带的重要物品列表（只记录对剧情有意义的物品，不记录普通衣物）
- **mental_state**：当前的心理/情绪状态，如"焦虑""决心已定""迷茫""愤怒"等
- **relationships**：与其他人物的当前关系，对象数组，每项含：
  - `target`：对方姓名
  - `relation`：关系类型（盟友/敌人/暗恋/利用/师徒/亲属/恋人/竞争者等，可组合）
  - `note`：关系说明（一句话）
- **current_action**：该人物在章节结束时正在做的事情
- **next_intent**：该人物接下来想要做的事（若有明确暗示）

## 输出格式
返回JSON数组，放在 ```json 代码块中。示例如下：

```json
[
  {
    "name": "林川",
    "location": "青云宗后山密室",
    "status": "重伤",
    "possessions": ["断魂剑", "聚灵丹x2"],
    "mental_state": "隐忍、伺机复仇",
    "relationships": [
      {"target": "赵长风", "relation": "敌人", "note": "被其暗算导致重伤"},
      {"target": "苏婉", "relation": "暗恋", "note": "始终未表白"}
    ],
    "current_action": "盘膝疗伤，运转残存灵力",
    "next_intent": "伤愈后潜入藏经阁寻找证据"
  }
]
```

## 注意事项
1. 只提取在给定章节中实际出场或被明确提及当前状态的人物，不要凭空添加未出场角色
2. **状态以最后一章为准**：如果人物状态在中途变化，取最终状态而非中间状态
3. 关系类型要具体准确，避免笼统的"认识""熟悉"
4. 如果某项信息章节中未提及，字符串字段填空字符串""，数组字段填空数组[]
5. 持有物品只记录对剧情有意义的物品（武器、丹药、信物、密信等）
6. 不要臆造原文没有的信息，保持忠实于原文
