# 世界观快照提取器

## 任务
你是一个小说世界观分析专家。请仔细阅读下面给出的小说章节内容，提取出已揭示的世界观设定。这些设定信息将作为后续章节生成的记忆上下文，确保AI在续写时保持世界观一致，不出现自相矛盾的设定。

## 设定类别
请将提取到的设定按以下类别归类（只提取章节中实际揭示的类别）：

- **geography**（地理）：地名、地形、方位、区域划分等
- **history**（历史）：过往事件、朝代更替、传说纪元等
- **power_system**（能力体系）：修炼等级、魔法体系、战力划分、突破规则等
- **social_structure**（社会结构）：宗门/势力/国家/阶层/组织架构等
- **economy**（经济）：货币、贸易、资源、产业等
- **technology**（科技/工艺）：器物、机关、阵法、炼丹炼器等技术
- **culture**（文化/风俗）：信仰、禁忌、节日、礼仪、语言等
- **other**（其他）：无法归入以上类别的设定

## 提取要求
对每一条已揭示的设定，提取以下字段：

- **category**：设定类别（取上面列出的英文key之一）
- **item**：设定项名称（简短，如"修炼等级""青云宗""灵石货币"）
- **content**：已揭示的具体内容（详细描述）
- **revealed_chapter**：揭示位置，第几章（数字）
- **hinted**：未揭示但暗示的内容（章节中有所暗示但未明确说明的部分，若没有填空字符串）

## 输出格式
返回JSON数组，放在 ```json 代码块中。示例如下：

```json
[
  {
    "category": "power_system",
    "item": "修炼等级",
    "content": "修炼分为炼气、筑基、金丹、元婴、化神五个大境界，每个大境界分初期、中期、后期、圆满四层",
    "revealed_chapter": 1,
    "hinted": "化神之上似乎还有更高境界，但宗门典籍未记载"
  },
  {
    "category": "social_structure",
    "item": "青云宗",
    "content": "青云宗是东域第一大宗，设有内门、外门、核心弟子三级，宗主之下设七位长老分管各务",
    "revealed_chapter": 1,
    "hinted": ""
  },
  {
    "category": "geography",
    "item": "东域",
    "content": "故事发生地为东域，东域有三大宗门鼎立，青云宗居首",
    "revealed_chapter": 2,
    "hinted": "除东域外似乎还有其他大域，但尚未详细提及"
  },
  {
    "category": "economy",
    "item": "灵石货币",
    "content": "修士之间以灵石为通用货币，分下品、中品、上品，1中品=100下品",
    "revealed_chapter": 2,
    "hinted": ""
  }
]
```

## 注意事项
1. 只提取章节中**实际明确揭示**的设定，不要从角色对话的只言片语过度推断
2. hinted 字段用于记录"作者明显在铺垫但尚未挑明"的内容，没有就填空字符串
3. 同一类别的多条设定应拆分为多个数组元素，每条聚焦一个设定项
4. content 要尽可能完整地记录已揭示的信息，便于后续章节保持一致
5. revealed_chapter 取该设定首次明确出现的章节号
6. 不要臆造原文没有的设定，保持忠实于原文
