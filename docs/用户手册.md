## 安装与启动

### 环境要求

- Windows 10/11 或 macOS
- Python 3.11+
- 推荐 8GB+ 内存

### 启动步骤

1. 打开项目根目录 `书斋V66-新重构`
2. 双击运行 `server.py` 或在命令行执行：

```powershell
python server.py
```

3. 等待服务启动，浏览器会自动打开 `http://127.0.0.1:8894`
4. 如需手机访问，添加 `--lan` 参数：

```powershell
python server.py --lan
```

> 手机需与电脑在同一局域网，启动后终端会显示手机访问地址。

### 目录结构

| 目录/文件 | 说明 |
| --- | --- |
| `server.py` | FastAPI 服务入口 |
| `backend/` | 后端服务（42 服务 + 30 路由 + 12 Agent） |
| `frontend/` | 前端 SPA（Vanilla JS） |
| `data/` | 项目数据存储 |
| `docs/` | 文档（API.md + 本手册） |

## 新手入门

### 第一步：创建项目

在侧边栏进入「项目管理」，或在 AI 面板输入：

```
新建一本仙侠小说叫《问道苍穹》
```

### 第二步：生成世界观

在「世界观」页面手动添加势力/地点/物品，或在 AI 面板输入：

```
添加势力青云门，正道第一修仙大派
添加地点幽冥谷，位于大陆极西的死亡禁区
```

### 第三步：生成大纲

在「大纲」页面使用模板或手动编写，或在 AI 面板输入：

```
生成全部章节大纲
```

系统会自动生成各章节大纲，可在连线框中拖拽调整结构。

### 第四步：写章节

逐章写作，或使用 AI 辅助生成：

```
生成第1章
续写500字
润色这段文字
```

### 第五步：检查与优化

使用校验功能确保质量：

```
检查第1章连贯性
检查第2章完整性
```

### 第六步：蒸馏优化

将已写章节蒸馏为结构化记忆，提升后续 AI 生成质量：

```
蒸馏已写章节
```

### 第七步：导出

在「导出」页面选择格式：

```
导出epub
```

## 常见问题 (FAQ)

### Q: 首次启动报错 "ModuleNotFoundError"

**A**: 确保 Python 版本为 3.11+，安装依赖：

```powershell
pip install -r requirements.txt
```

### Q: AI 生成没有反应

**A**: 
1. 检查 `backend/ai_config.json` 中的 API Key 是否配置正确
2. 在「设置→AI模型」中测试连接
3. 查看终端日志是否有错误信息

### Q: 如何备份数据？

**A**: 项目数据存储在 `data/novel_projects/` 目录下。可直接复制该目录备份，或使用云同步功能。

### Q: 端口被占用怎么办？

**A**: 系统会自动探测 8894-8913 的可用端口。如果整个范围都被占用，关闭占用端口的程序后重启。

### Q: 支持多少种小说题材？

**A**: 支持 24 种题材：仙侠、都市、玄幻、科幻、悬疑、言情、历史、军事、游戏、末世、重生、穿越、武侠、灵异、同人、轻小说、古言、职场、电竞、无限流、系统流、快穿、甜宠、星际。

### Q: 大纲模板有哪些？

**A**: 内置退婚流、重生复仇、都市系统、玄幻升级、宫斗、无限流、种田等模板。

### Q: 蒸馏和拆书有什么区别？

**A**: 
- **蒸馏**：将你自己的章节内容提炼为结构化记忆，压缩上下文体积
- **拆书**：分析经典作品的写作技法、结构、节奏，转化为写作参考

### Q: 时间线计划 vs 实际对照如何使用？

**A**: 在「时间线」页面为每章填入「计划」列（大纲预期内容），写作完成后系统会自动提取「实际」列的正文梗概，AI 对比两者识别偏离并给出修复建议。

### Q: 如何导入已有小说？

**A**: 在「导入」页面粘贴或上传已有小说文本，系统会自动分章、提取角色、生成摘要和大纲。

### Q: 云端同步安全吗？

**A**: 云同步通过 WebDAV 协议实现。你可以使用自己的 WebDAV 服务器（如 NextCloud、ownCloud），数据不会上传到第三方云端。配置路径：设置→同步设置。
