# 书斋 V66 — AI 小说创作智能助手 项目功能分析报告

> **分析时间**：2026-07-22
> **项目路径**：`H:\小说\书斋V65 - 副本`
> **项目性质**：AI 驱动的小说创作工作室，而非阅读器

---

## 一、项目概述

**书斋 (Shuzhai)** 是一个面向网文作者的全栈 AI 小说创作平台，版本号 V66（代码中标注 V65/V66 并存）。核心定位是"AI 辅助小说创作智能助手"，提供从构思、写作、校验、设定管理到导出发布的全流程工具链。

### 核心理念
- **AI 生成 + 人工掌控**：AI 负责草稿生成，作者负责审核修订
- **设定驱动写作**：通过 Truth Ledger（事实账本）、世界观设定、蒸馏记忆确保长篇一致性
- **本地优先 + 可选云端**：支持完全离线使用（APK 模式 / 本地模型），也可接入 DeepSeek/OpenAI API

### 2.1 技术栈总览

| 层级 | 技术选型 | 说明 |
|------|---------|------|
| **后端框架** | FastAPI 0.138 + Uvicorn 0.49 | 异步 REST API 服务 |

### 3.2 AI 写作核心

#### 3.2.1 多模型路由

```
DeepSeek V4 (默认) → 支持 thinking 模式
OpenAI GPT-4o     → 兼容接口
Ollama 本地模型    → 离线 fallback（qwen3:14b）
```

**按任务类型自动选模型**：
- `architecture` → deepseek-v4 / gpt-4o（架构/大纲/复杂设计）
- `writing` → deepseek-v4-flash / gpt-4o-mini（正文写作）
- `check` → deepseek-v4-flash（检查/审核）
- `summary` → deepseek-v4-flash（摘要/提取）
- `chat` → deepseek-v4-flash（对话/问答）

#### 3.2.2 章节生成引擎

**核心流程**：`生成 → 硬校验 → 后处理 → 大纲覆盖 → 返回`

1. **Prompt 构建**（generator_prompts.py）：
   - 世界观设定注入（WorldSettings）
   - 设定库注入（道具/功法 + 势力/组织）
   - 全书大纲上下文
   - 角色状态注入（按需，最多8个）
   - 蒸馏记忆注入（替代原文，~10倍压缩）
   - 用户偏好注入（风格/剧情/节奏/禁忌词）
   - 技能包规则注入（如 anti-ai-base 技能包）
   - 向量记忆检索（语义相关前文）

2. **后处理**（_post_process）：
   - 去除 AI 生成的章节标题
   - 去除协作交流痕迹
   - 空行整理

3. **校验 Gate**（_run_hard_checks）：
   - 禁用词检测（FORBIDDEN_WORDS，50+ 词）
   - 禁用情节检测（FORBIDDEN_PLOTS，15+ 模式）
   - 字数/内容长度校验

4. **流式生成**（SSE）：支持逐 token 推送，实时显示生成进度

5. **批量生成**：后台任务管理器，支持进度追踪/取消/ETA 估算

#### 3.2.3 AI 编辑与修复

- AI 修复选中文段
- AI 续写
- AI 编辑指定范围
- 编辑批注自动清除（后端安全网 + 前端双重保障）

### 3.3 设定管理（Truth Ledger）

这是项目的核心差异化功能，确保长篇小说的一致性。

#### 3.3.1 角色状态追踪

```python
CharacterState:
  - 基本信息：name, location, emotion, health, realm, is_alive
  - 关系网络：relationships (Dict)
  - 物品清单：possessions
  - 已知秘密：secrets_known
  - 叙事追踪：last_seen_chapter, arc_stage
```

支持 CRUD 接口：`/api/world/characters/*`

#### 3.3.2 伏笔管理系统

```python
Foreshadowing:
  - 核心字段：content, planted_chapter, status
  - 状态机：planted → active → recovered → abandoned
  - 悬念编排：arc_type (短/中/长), strength (1-5), hook_type (13式)
  - 13 种钩子类型：突然揭示、紧急危机、未完成动作、身份反转、两难选择、神秘线索、时间限制、承诺威胁、离奇消失、言外之意、意象钩子、回声钩子、留白钩子
```

#### 3.3.3 叙事状态快照

- 创建快照：`POST /api/snapshot/take`
- 列表/恢复：`GET /api/snapshot/list`，`POST /api/snapshot/restore`
- 版本管理：支持多版本快照，任意时间点回滚

#### 3.3.4 结构化设定库

| 类型 | 字段 | 路由 |
|------|------|------|
| 道具/功法 | id, name, type, grade, owner, description, destroyed | `/api/settings/artifacts` |
| 势力/组织 | id, name, type, leader, members, description, status | `/api/settings/factions` |

#### 3.3.5 章节日志

每章记录：关键选择、代价、新伏笔、已回收伏笔、角色变化、Strand Weave 线型（Quest/Fire/Constellation）

### 3.4 记忆系统

#### 3.4.1 向量记忆（RAG）

- **Embedding 模型**：all-MiniLM-L6-v2（本地运行，384维）
- **向量库**：FAISS（加速） + NumPy（兜底）
- **6 种记忆类型**：对话/设定事实/剧情事件/世界观知识/角色偏好/角色能力
- **遗忘机制**：基于重要性和访问时间的自动清理
- **语义检索**：生成章节时自动检索最相关的前文记忆，注入 Prompt

#### 3.4.2 记忆蒸馏

将完整章节压缩为结构化记忆，实现约 **10 倍上下文压缩**：

- 8 种提取器：
  - 人物状态提取（character-state-extractor）
  - 情节进度提取（plot-progress-extractor）
  - 伏笔追踪（foreshadowing-tracker）
  - 情节结构提取（plot-structure-extractor）
  - 关系映射（relationship-mapper）
  - 世界观提取（worldbuilding-extractor）
  - 世界观快照（worldbuilding-snapshot）
  - 写作技巧提取（writing-technique-extractor）

- 蒸馏后的记忆以 JSON 存储，支持增量更新
- 前端蒸馏面板：可视化蒸馏状态、触发蒸馏任务

#### 3.4.3 记忆综合器（memory_synthesizer）

将多维度蒸馏记忆合成为结构化 Prompt 上下文，在生成新章节时自动注入。

### 3.5 创作工作流

#### 3.5.1 7 步创作工作流

```
Step 1: 基础设定     → 书名/类型/一句话简介
Step 2: 全书大纲     → AI 生成结构化大纲（dict格式）
Step 3: 角色设定     → 角色名/身份/性格/背景
Step 4: 分卷纲要     → 分卷规划 + 章节概要
Step 5: 章节大纲     → 逐章大纲
Step 6: 正文创作     → AI 生成 + 人工修订
Step 7: 时间线对照   → 计划 vs 实际差异分析
```

工作流状态持久化到 `data/workflow_state.json`，支持断点续传。

#### 3.5.2 首次启动向导

前端 `wizard.js`：引导用户完成首次项目创建流程。

### 3.6 校验与分析

#### 3.6.1 内容校验

- 硬校验（生成时自动执行）：禁用词/禁用情节/字数
- 软校验（手动触发）：AI 味检测、情节一致性、角色一致性
- 校验面板：可视化问题列表，支持逐条修复

#### 3.6.2 AI 分析面板

| 分析维度 | 描述 |
|---------|------|
| AI 味检测 | 检测 24 种 AI 写作特征（基于 Humanizer-zh） |
| 文风指纹 | 分析写作风格特征 |
| 伏笔引力 | 伏笔密度和回收进度 |
| 线程分布 | 多条故事线分布情况 |

#### 3.6.3 时间线对照

- 分卷/分章的计划大纲 vs 实际正文对照
- AI 自动比对差异（Divergence）
- 差异状态管理：待处理 / 已接受 / 已修复
- 支持手工编辑 + AI 对照重新生成
