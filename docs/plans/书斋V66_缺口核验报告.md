## 关键纠正（用户认知与代码不符之处）

### 纠正 1：audit.py 存在，不是"不存在"
- **用户声称**：Layer 2 audit.py 不存在
- **代码实情**：`backend/services/audit.py` 共 1166 行，含 `detect_ai_flavor`、`detect_power_collapse`、`run_extended_audit` 等完整实现
- **真实缺口**：audit.py 中 **6 项**扩展审计无实现代码（logic_gaps / character_break / pov_drift / setting_conflict / spatial_consistency / climax_missing），被静默跳过。但 buzzword_forbidden、dead_revival、realm_jump 三项**已有实现**
- **影响**：缺口是真实的，但比用户描述的"7 项全部跳过"轻——实际是 6 项跳过、3 项已实现

### 纠正 2：C5 协作式草稿模式已经存在
- **用户声称**：编辑器与 AI 对话分离，无法选中文字调用 AI 局部改写
- **代码实情**：`frontend/js/modules/creative-tools.js` 实现了四大工具：
  - Describe（描写增强）：选中→AI增强→替换或追加
  - Expand（场景扩写）：选中→AI扩写→替换或对比
  - Rewrite（灵活重写）：选中→AI生成3个候选→用户选择替换
  - Feedback（5维反馈）：选中→AI评分+雷达图
- **入口**：编辑器工具栏四个按钮（index.html:685-688）
- **唯一瑕疵**：Creative Tools 以 overlay 面板弹出，不是"选中文字后内联浮现的工具条"。但核心功能完整存在

### 纠正 3：C4 预览确认有半套机制
- **用户声称**：Gate 通过后自动落盘，用户没机会看
- **代码实情**：
  - 后端确实在 Gate 通过后立即 `set_content` + `save_all`（generate.py:1170-1171）—— **磁盘已写入**
  - 但前端有 `DraftManager`（draft-ui.js:116-147）进入草稿模式，支持采纳/丢弃对比
  - 丢弃仅恢复编辑器显示，不主动覆盖磁盘（依赖后续 AutoSave）
- **真实问题**：落盘时机过早，DraftManager 是"事后对比"而非"事前确认"

### 纠正 4：G 全局 UI 设计系统已存在
- **用户声称**：每个模块独立写 CSS，无设计系统
- **代码实情**：`components.css`（625行）+ `style.css` 变量体系完整：
  - 18 个颜色变量、8 级间距 scale、圆角/阴影/字号/动效/聚焦环全覆盖
  - 50+ 组件类均使用 `var(--xxx)`
- **真实缺口**：`check-panel.css`（275行）是未改造孤岛——36 处硬编码颜色，0 个 CSS 变量引用；部分 JS 文件有内联颜色

### 纠正 5：B 大纲交互问题被夸大
- **用户声称**：分类需逐条点开查看
- **代码实情**：同标签页内的设定条目**默认全部展开**（settings-group-header 硬编码 expanded）
- **真实问题**：① 6 个步骤在不同标签页，需切换而非单页概览 ② 无"全部展开/折叠"全局开关
