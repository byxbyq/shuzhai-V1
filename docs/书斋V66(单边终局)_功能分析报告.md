## 2. 后端核心模块分析

### 2.1 AI 客户端（`backend/ai_client.py`）

**支持的 Provider（5 个）：**

| Provider | 说明 | 环境变量 |
|---|---|---|
| deepseek | DeepSeek V4 系列（默认） | `DEEPSEEK_API_KEY` |
| ollama | Ollama 本地模型 | — |
| openai | OpenAI GPT 系列 | `OPENAI_API_KEY` |
| doubao | 豆包（火山引擎 ark，OpenAI 兼容接口） | `DOUBAO_API_KEY` |
| kimi | Kimi / 月之暗面 Moonshot（OpenAI 兼容接口） | `KIMI_API_KEY` |

- API Key 读取优先级：环境变量 → `data/ai_config.json` 的 `api_key` 字段。
- 配置写入采用**原子写**（唯一临时文件 + `os.replace`），防止进程被杀导致密钥丢失。
- 使用 `httpx.Client` 连接复用，300 秒超时（connect 10s）。
- 内置用量追踪：记录到 `data/ai_usage.json`，含各 Provider 单价估算（元/百万 token）。

### 2.2 模型注册表（`backend/services/model_registry.py`）

- 内置各 Provider/模型的真实上下文窗口、max_output、**思考强度档位**（off/low/medium/high/max）。
- 按任务类型自动决定弹性思考强度：JSON 结构化任务 → 降档（small JSON 用 low/off）；正文生成任务 → 升档（thinking=high/enabled 且上调输出预算）。
- 已登记模型示例：deepseek-v4 / deepseek-v4-flash / deepseek-v3 / gpt-4o / gpt-4o-mini / gpt-4.1 / doubao-pro-32k / doubao-pro-128k 等。

### 2.5 六席位流水线（`backend/services/six_seat_pipeline.py`）

基于 FlowGraph/FlowExecutor 构建的固定 DAG 流水线：

```
planner → writer → reviewer → reviser → factcheck → librarian
大纲席    正文席    校验席     修订席     防幻觉席    台账席
```

- 复用现有 Agent：OutlineAgent / ChapterAgent / ValidateAgent / RewriteLoop（有界改写循环）/ HallucinationGuard / CommitmentTracker。
- 对外提供 `run_six_seats(chapter_index, project_dir)`，API 为 `/api/flow/six-seat/run`。

### 2.6 小说引擎（`backend/novel_engine/`）

**engine_core.py** — 小说引擎核心，桥接六轴碰撞图与书斋模块（AppState / TruthLedger / VectorMemory）：

- 一期：六轴关系图 + 碰撞检测 + 碰撞事件转自然语言灵感（brainstorm_cards 格式）。
- V2 扩展（四期融合）：
  - `WorldTimeline` 世界时间轴管理
  - `SwimlaneManager` 角色泳道生命周期管理
  - `GoalScheduler` 多层级目标调度
  - `CausalCollisionScheduler` 六轴增强版碰撞调度
  - `ConsistencyChecker` 全局一致性校验
  - `WorldRuleGuard` 世界观规则守卫
  - `TimelineBranch` 时序回溯分支存档

**six_axis_graph.py** — 六轴关系图（角色碰撞检测系统）：

| 轴 | 含义 | 正/负 |
|---|---|---|
| FB（前/后） | 因果关系 | 推动 / 阻碍 |
| UD（上/下） | 层级关系 | 仰视 / 压制 |
| LR（左/右） | 利益关系 | 合作共赢 / 竞争对立 |
| SD（深/浅） | 理念关系 | 共鸣 / 冲突 |
| IO（内/外） | 交互关系 | 亲密 / 疏离 |
| TM（时序） | 时间关系 | 先后顺序权重 |

- 核心算法 `detect_convergence()`：沿边传播激活，找到多来源汇聚节点 = 碰撞点。
- 配套 API：`/api/engine/*`（status / collide / graph / reset / v2/* 系列）。

## 5. 核心功能特性全景

### 5.1 写作九步工作流

`step-constants.js` 定义 9 个步骤：世界观 → 人物 → 全书大纲 → 分卷 → 章节大纲 → 连线框 → 写作 → 时间线 → 草稿定稿。前端通过步骤常量统一引用，支持分卷（volumes）、章节大纲、连线框画布、时间线管理。

### 5.2 生成体系

- 单章生成（`/api/generate/start` + 任务状态轮询）、批量生成全部章节（`/api/generate/all-chapters`）。
- 生成确认门（`/api/generate/gate|confirm`）、覆盖检查（`coverage-check`）、灵感转蓝图/全书大纲（`inspiration-to-*`）。
- 大纲生成：全书大纲 / 章节大纲 / 分卷大纲 / 下一章大纲。
- 六席位流水线（planner→writer→reviewer→reviser→factcheck→librarian）通过 Flow Engine 驱动。

### 5.3 质检与审计体系

- 校验 API：单类型 `/{check_type}`、批量 `/batch`、`/all-in-one`。
- AI 味检测（`ai_flavor.py`）：突发性 CV、AI 高频词、公式化过渡、旁白越位、塑料句式、否定转折、对话标签、升华句、上帝视角、工程词等维度评分。
- 风格提取/对比（`/api/audit-log/ai-flavor|style-extract|style-compare`）、战力崩塌检测（`power-collapse`）、扩展审计（`extended-audit`）。
- 防幻觉守卫（P3-2）、承诺台账（P2-4）、一致性检查、编辑审校、章节修复。

### 5.4 记忆与知识库

- 向量记忆（RAG）：6 种记忆类型（对话/设定/剧情/世界观/角色/能力）、遗忘机制、BGE embedding 本地运行、FAISS+NumPy。
- 记忆 API：增删改查、语义检索、生成前检索、共享记忆、嵌入模型切换、上下文预览。
- 知识库 API：模板导入、自定义导入、打包导出/导入、检索、包管理。

### 5.5 拆书与蒸馏

- 拆书（`deconstruct.html` + `/api/deconstruct/*`）：分块总结/合并/分析、多维拆解、任务化异步处理。
- 蒸馏（`/api/distill/*`）：将爆款小说蒸馏为可执行写作技能包（RIA-TV++ 流水线），提取器 8 个维度。
- 技能导入（`/api/skills/*`）：技能包导入/列表/蒸馏/深度分析。

### 5.6 世界观与事实账本

- 世界观：势力 / 物品 / 地点 / 约束 / 钉选（`/api/world/*`）。
- 事实账本 TruthLedger（`/api/ledger/*`）：角色状态、时间线、钩子（hook）增删激活/放弃、伏笔（read-pull）、线团统计（strand-stats）。
- 设置页（`/api/settings/*`）：工件（artifacts）/ 阵营（factions）。

### 5.7 时间线引擎

- 每章节的计划/实际时间线、注释、分叉（divergence）管理、对比、自动修复、定稿（`/api/timeline/*`）。
- Novel Engine V2：世界时间轴、角色泳道、目标调度、因果碰撞、一致性校验、世界观规则守卫、时序分支存档。

### 5.8 多 Agent 圆桌与角色对话

- `/api/chat/characters|talk`：与小说角色对话。
- `/api/agent/chat`：Agent 会话。
- RoundtableSession：多 Agent 多轮结构化讨论（主持人 + 参与者并发响应 + 最终总结）。

### 5.9 排行榜与题材分析

- 平台扫描（`/api/ranking/scan`）、对比、趋势、建议、题材分析；`ranking_crawlers.py` 抓取。

### 5.10 导出与同步

- 导出：TXT / EPUB / PDF / 平台格式 / 剧本（`/api/export/*`）。
- 同步：配置 / 测试 / 推送 / 拉取（`/api/sync/*`），`sync_apk_backend.py`、`sync_to_phone.py` 支撑 APK 数据同步。

### 5.11 其他

- 项目快照（`/api/snapshot/*`）：快照/恢复。
- 章节快照（`/api/chapter/snapshots|restore|diff`）。
- 项目钩子（`/api/project/hooks/*`）：add/advance/recover/abandon。
- 项目状态记忆（`/api/project/state-memory`）、实体重命名（`/rename-entity`）。
- 文件解析（`/api/file/parse`）、小说导入（`/api/import/novel`）、角色提取（`/extract-characters`）。

## 9. 本版本独有特性小结（相对旧版差异点）

1. **白城主 Flow Engine**：完整 DAG 节点编排引擎（图模型/注册表/异步执行器/AI Composer/ComfyUI 适配/run_code 沙箱/依赖管理），含前端 SVG 连线编辑器 `white-city-editor.js` 与 `/api/flow/*` API。
2. **六席位流水线**：planner→writer→reviewer→reviser→factcheck→librarian 固定 DAG，基于 Flow Engine 同步执行。
3. **Novel Engine V2 调度层**：WorldTimeline / SwimlaneManager / GoalScheduler / CausalCollisionScheduler / ConsistencyChecker / WorldRuleGuard / TimelineBranch（`/api/engine/v2/*`）。
4. **六轴关系图碰撞检测**：FB/UD/LR/SD/IO/TM 六轴角色关系建模 + 汇聚碰撞检测（`/api/engine/collide`）。
5. **AI Composer 自然语言编排**：输入自然语言 → 联网检索 API 文档 → 生成 MiniPipelineNode 配置 + 自动连线建议。
6. **弹性思考强度**：model_registry 按任务类型自动升降思考档位，保护结构化输出。
7. **离线 APK 双轨**：前端直连大模型（offline-ai）+ IndexedDB 全量项目存储（offline-db）+ Service Worker PWA 三件套。
